# 트러블슈팅 보고서

실습 중 발생한 오류에 대해 **증상 → 원인 가설 → 검증 방법 → 조치 내용 → 결과 → 재발 방지** 순서로 기록합니다.

---

## 사례 1. (제목 작성)

| 항목 | 내용 |
| :--- | :--- |
| **증상(문제 상황)** | 예: EC2 생성 후 외부에서 접속 불가 / SSH 접속 타임아웃 등 |
| **원인 가설** | 예: 보안 그룹 인바운드 규칙 또는 Route Table 설정 누락 |
| **검증 방법** | 예: AWS 콘솔에서 Security Group 인바운드 확인, `curl` / `docker compose logs` 확인 |
| **조치 내용** | 예: 해당 포트/규칙 수정 또는 설정 변경 |
| **결과** | 예: 정상 접속(200 OK) 확인 |
| **재발 방지** | 예: 배포 전 체크리스트 확인 |
